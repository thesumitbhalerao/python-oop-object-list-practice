# Python OOP Homework – Objects and Lists

## Project Information

- **Subject:** Python Programming
- **Topic:** Classes, Constructors, Objects, Lists, and Conditions

## About This Project

This repository contains my Python homework on Object-Oriented Programming (OOP). The assignment demonstrates how to create classes, initialize object attributes using constructors, create multiple objects, store objects in lists, and filter data using conditional statements.

## Files Included

| File Name | Description |
|---|---|
| `class_01.py` | PMPML bus objects and bus route filtering |
| `class_02.py` | Mess objects and vegetarian mess filtering |
| `class_03.py` | Tea House objects and price filtering |
| `class_04.py` | PG objects and rent filtering |
| `class_05.py` | Perfume objects and price filtering |
| `complete_db.py` | Combines objects from all five classes into one list |

## Python Concepts Covered

- Classes and objects
- Constructor (`__init__`)
- Instance attributes using `self`
- Creating multiple objects
- Lists and the `append()` method
- Combining lists using the `extend()` method
- `for` loops
- `if` conditions
- Displaying filtered results

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run an individual file using:

   ```bash
   python class_01.py
   ```

5. To run the combined database example, use:

   ```bash
   python complete_db.py
   ```

## Learning Outcome

This homework helped me practise creating multiple objects, storing them in lists, applying conditions to filter data, and combining objects from different classes into a single list.
